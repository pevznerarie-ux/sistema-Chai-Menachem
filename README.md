# Sistema Chai Menachem

Sistema de gestão da comunidade: famílias, relacionamento, financeiro, eventos, comunicação e relatórios.

Esta versão é a **prévia**, com dados de exemplo. Nada do que é cadastrado fica salvo.

- `src/` — código da página, em partes
- `build.sh` — junta `src/` em `public/index.html`
- `server.js` — servidor que entrega a página (`npm start`)
